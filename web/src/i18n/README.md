# 英文国际化：接入进度

采用 i18next + react-i18next，保留 Next 静态导出及现有 URL。Go 服务继续提供同一份静态文件。

范围更新（2026-11-10）：按用户要求，AI 输出和提示词不纳入国际化。继续处理界面、非 AI 系统文案、内置展示说明、导出固定文案与通知；不修改模型输出正文和提示词。

- 登录前及全局顶栏右上角的语言选择；浏览器记忆选择、跨标签页同步、网页 lang/title/description 更新。
- 通用状态、分页、日期/时间控件及部分基础组件的辅助文案。
- 九类 `@` 引用的中英文搜索别名与显示名称。新文本使用 `@[finding#123 名称]` 等稳定 kind；前后端继续识别历史中文格式。
- 认证及 HTTP Basic Auth 接口增加 `code`/`params`，保留旧 `error` 字段；前端保留原错误消息作为未知错误码的回退。
- 系统设置各分类及搜索、版本与更新、访问验证、代理池、出口 IP、运行时开关、快捷键等固定界面文案；设置搜索同时接受中英文。代理出口提醒增加结构化码，兼容旧提醒字符串。
- 仪表盘固定标题、图例、统计标签、空态与相对时间；对话列表、创建/删除/重命名/置顶、输入区、附件操作、执行记录的固定标签、旁路问答、Todo 面板与审批定位提示。
- 计划任务页的列表、创建/编辑表单、日期/时区、运行时间线、批量操作，以及名称/备注编辑器；已知后端提示和已保存历史系统文案在展示时按语言转换。
- 任务列表、创建任务、分类管理、并发设置、归档/还原/删除确认、任务模板控件、LLM 配置链和任务级资产规则编辑器。AI 描述、目标、模板正文和上传清单协议保持原文。
- 通知推送页的六类渠道表单、全局设置、过滤条件摘要、投递列表、状态与时间、常见校验错误及演示模式提示；Webhook 模板语法和第三方响应保留原文。
- 数量文案的英文单复数；切换语言时设置表单不重新加载，已展开的执行记录按新语言显示标签，原始命令与输出保持原文。

中文是默认语言。静态 HTML 和首次客户端渲染使用中文，挂载后读取 `localStorage.artex_locale`。保存过英文偏好的用户在刷新时可能短暂看到中文。

## 页面覆盖（2026-11-10 本轮）

27 个主页面入口及任务详情 11 个标签页（含情报）已接入固定 UI 文案，详见 [逐页验收清单](./PAGE-AUDIT.md)。发现列表的四种视图、发现详情/归并详情、复测、证据、导出选项；资产、流量、请求重发、工具执行、LLM 录制、同步、工作空间；Agent/MCP/Skill/工具/LLM 编辑器、命令/资产拦截、审批记录和系统日志的界面标签也已迁移。

补充约 2,000 条成对界面资源 `screen-catalog.json`。`useUITranslation()` 的 `ui` 随渲染语言更新，`liveUI` 用于稳定的轮询/请求回调。日期显示、探索图边标签、资产图文字、内置 Agent 默认名称及说明也随语言更新。用户编辑的 Agent 名称/说明保持原文。

已知固定校验错误与 Repeater 默认分组仅在展示边界转换，不翻译请求正文和协议。后台返回的其他系统事件、业务错误、导出文件固定标题/列名和默认通知正文仍需继续覆盖，不能据此宣称全站国际化完成。

浏览器操作工具两次返回 `Local browser use is disabled in Work settings`（包括指定内置浏览器）。因此本轮实际逐页点击、打开全部弹窗、数据加载后的全量验收、窄屏和长英文布局均未完成。自动渲染测试检查初始页面、任务标签、带数据的漏洞表格和 Repeater；不能替代实际浏览器验收。

## 后续开发约定

- 在 `messages.ts`（或其拆分模块）同时登记中英文。组件内调用 `useTranslation()` 或 `useLiveTranslation()` 的 `t`，动态派生导航、状态和选项，避免模块级缓存译文。`t` 保留随语言变化的函数身份以兼容 React Compiler；仅生命周期回调使用稳定的 `liveT`，避免语言变化引起表单数据重载。
- 对象 ID、枚举、API 字段、工具 key、DSL 与引用 kind 保持稳定。用户名称、备注、自定义模板、历史报告、请求响应和原始命令输出保持原文。
- 使用 `useDateLocale()` 处理展示日期；存储日期、API 格式和时区语义保持原样。数量文案使用 `count` 和复数资源。
- 审批解释在 `intercept/prompt.go` 仍按中文固定短语解析，按现有协议保留提示词与解析行为；只翻译界面上的固定标签。`[模型]`、人工审批来源、默认“新对话”和“超过”截断判断等历史约定在迁移展示文案时仍需保留兼容。执行记录已用稳定的 `command`/`output` 类型替代 `label === "命令"` 判断，避免英文标签影响命令提取。
- 界面语言不会改变 AI 输出语言；AI 输出和提示词均在本次范围之外。
